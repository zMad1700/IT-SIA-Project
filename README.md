# ScholarHub — Scholarship Information System

## Database design

The Supabase schema is in [supabase/schema.sql](supabase/schema.sql). Run it in Supabase SQL Editor before using cloud features. The requirements analysis, ERD, business rules, and normalization notes are in [supabase/ERD.md](supabase/ERD.md).

Copy `.env.example` to `.env` and set the Supabase URL and anon key to enable cloud authentication and data storage.
